# تطبيق وَرَتِّلْ - متابعة حفظ القرآن وإدارة الحلقة (PWA)

تطبيق ويب تقدمي (Progressive Web App) متكامل لمتابعة حفظ القرآن الكريم، وتسميع جزء عم، وإدارة الطالبات والغياب والمقررات اليومية، مصمم خصيصاً لتجربة شاشات الهواتف الذكية مع دعم العمل بدون إنترنت (Offline-First) وحفظ البيانات محلياً.

## ✨ المميزات الرئيسية

1. **تصميم متقدم ومخصص للهواتف (UI/UX Pro Max)**:
   - دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL).
   - تباين وألوان إسلامية راقية (الزمردي الداكن والذهبي الفاخر).
   - تصميم زجاجي عصري (Glassmorphism) مع حدود ناعمة وتأثيرات ضوئية.
   - تبديل سلس بين الوضع الليلي (Dark Mode) والوضع النهاري (Light Mode) مع حفظ التفضيل.
   - أهداف لمس مريحة للشاشات اللمسية (أكثر من 48 بكسل).

2. **سورة وصفحة اليوم**:
   - عرض تاريخ اليوم باللغة العربية مع السورة والصفحة المقررة.
   - زر لإضافة أو تعديل مقرر اليوم.
   - قائمة ذكية تضم سور القرآن الـ 114 مع بحث سريع واقتراح تلقائي لرقم بداية الصفحة.
   - تحقق من صحة رقم الصفحة (1 إلى 604).

3. **إدارة الطلاب والتحقق**:
   - إضافة وتعديل بيانات الطلاب:
     - اسم الطالب بالكامل.
     - رقم الهوية الوطنية: **تحقق صارم من أن الطول 9 أرقام بالضبط** مع فحص عدم التكرار.
     - رقم الجوال.
     - تاريخ الميلاد.
     - مكان الميلاد.
   - البحث الفوري بالاسم لتصفية الطلاب بلمسة واحدة.
   - بطاقة لكل طالب تحتوي على أزرار الاتصال الهاتفي ومراسلة الواتساب الفورية.
   - نافذة ملف شخصي متكاملة تعرض كافة بيانات الطالب وسجل غياباته عبر التواريخ المختلفة.

4. **تسجيل الغياب وتاريخ الأيام السابقة**:
   - زر "تسجيل غياب اليوم" يفتح نافذة سريعة لتحديد الغائبين بلمسة واحدة.
   - عداد مباشر يوضح عدد الغائبين والحاضرين.
   - شاشة منفصلة مخصصة لـ "سجل الأيام السابقة":
     - عرض زمني لكل يوم سابق وتاريخه.
     - السورة ورقم الصفحة المقررة لذلك اليوم.
     - عدد وأسماء الطلاب الغائبين في ذلك اليوم.
     - زر لتعديل غياب أي يوم سابق وحفظ التغييرات فورياً.

5. **العمل بدون إنترنت (Offline) وتطبيق PWA**:
   - تخزين محلي كامل في المتصفح عبر `localStorage`.
   - ملف `sw.js` لتخزين كاش كامل لكافة الأصول والصفحات.
   - ملف `manifest.webmanifest` وأيقونات عالية الدقة تتيح تثبيت التطبيق على الشاشة الرئيسية للهواتف الذكية (Android و iPhone).

## 🚀 طريقة التشغيل

- يمكنك فتح ملف `index.html` مباشرة في أي متصفح حديث.
- لتثبيته كتطبيق على الهاتف: افتح الرابط في متصفح هاتفك واختر **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)**.
